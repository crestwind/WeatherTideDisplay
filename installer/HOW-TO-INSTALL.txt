WEATHER & TIDE DISPLAY - INSTALL / UPDATE FROM THIS FLASH DRIVE
================================================================

The same steps install it the first time AND update it later.
Updating replaces the program but keeps that computer's settings (location, units, etc.).

LINUX (e.g. the Seneca)
  1. Plug in the flash drive.
  2. Open a terminal: press the Windows key, type  terminal  and press Enter.
  3. Type  sh  and then a SPACE (don't press Enter yet).
  4. In the file manager, open this WeatherTideDisplay folder and DRAG
     INSTALL-Linux.sh into the terminal window - it fills in the location.
  5. Click the terminal and press Enter.
  6. Double-click "Weather & Tide Display" on the desktop.
     (If it asks, right-click it and choose "Allow Launching".)

  "Permission denied"?  You left out  sh  at the start - add it.
  It uses Chromium if installed, otherwise Firefox (included with Debian).

WINDOWS
  1. Plug in the flash drive and open it in File Explorer.
  2. Open the WeatherTideDisplay folder and double-click INSTALL-Windows.bat
     (If Windows shows "Windows protected your PC", click More info -> Run anyway.)
  3. Double-click "Weather and Tide Display" on the desktop.
  Uses Google Chrome if installed, otherwise Microsoft Edge.

AFTER UPDATING
  If the display is already open, close it (Alt+F4) and reopen it from the shortcut.

FIRST RUN
  The settings panel opens - type your town or ZIP, pick it from the list, press Save.

IN THE DISPLAY
  S or Enter = settings    F = full screen    R = refresh    Alt+F4 = close

TO REMOVE
  Linux:   same as installing, but drag in UNINSTALL-Linux.sh
  Windows: double-click UNINSTALL-Windows.bat

WHERE IT INSTALLS
  Linux:   ~/WeatherTideDisplay
  Windows: %LOCALAPPDATA%\WeatherTideDisplay

The full manual is app/README.md. The version on this drive is in app/VERSION.
